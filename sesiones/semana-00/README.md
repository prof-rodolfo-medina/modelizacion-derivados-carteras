## Cómo trabajarlo

1. Abre el cuaderno con el botón **Open in Colab** (no hace falta instalar nada).
2. Ejecuta las celdas en orden con **Shift + Enter** y resuelve cada ejercicio sustituyendo `None` por tu código.
3. La celda de cada ejercicio te dice si es correcto. Las soluciones están al final.
4. Termina con la lista de comprobación de la sección 9.
